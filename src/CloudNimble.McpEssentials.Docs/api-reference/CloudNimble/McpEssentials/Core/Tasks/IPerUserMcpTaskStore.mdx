## Summary

An `IMcpTaskStore` that isolates tasks per authenticated user and exposes
[ClaimsPrincipal](https://learn.microsoft.com/dotnet/api/system.security.claims.claimsprincipal) overloads for every client-facing operation.

## Remarks

The MCP C# SDK calls the `IMcpTaskStore` methods, which have no user parameter.
Authenticated stores resolve the caller from the current-user callback captured at construction.
Hosts, tests, and durable providers that already have a [ClaimsPrincipal](https://learn.microsoft.com/dotnet/api/system.security.claims.claimsprincipal)
call the overloads on this interface instead.

Client-facing operations (create, get, cancel, resolve) require an authenticated principal
and treat another user's task as missing. Server-side completion (set completed, set failed,
set input requests) stays on `IMcpTaskStore` and skips the live-user check because
the SDK runs those from a background DI scope after the originating request is gone.

Every store exposes `CancellationToken)` so a host can flush expired rows on its
own schedule. The base class also pulses that flush after create and on get unless
`AutoSweep` is turned off.

### <Icon icon="function" iconType="duotone" color="#419AC5" size={24} className="mr-2" /> SweepExpiredAsync <Badge color="orange">Abstract</Badge>

Removes snapshots the store's discard criteria say are gone.

#### Syntax

```csharp
System.Threading.Tasks.Task SweepExpiredAsync(System.Threading.CancellationToken cancellationToken = null)
```

#### Parameters

| Name | Type | Description |
|------|------|-------------|
| `cancellationToken` | `System.Threading.CancellationToken` | Cancellation token for the operation. |

#### Returns

Type: `System.Threading.Tasks.Task`
A task that completes when the pass finishes.

#### Exceptions

| Exception | Description |
|-----------|-------------|
| `OperationCanceledException` | *cancellationToken* was cancelled during the pass. |

#### Remarks

Always runs a full pass. Automatic create/get pulses are separate and throttled.
Set `AutoSweep` to [`false`](https://learn.microsoft.com/dotnet/csharp/language-reference/builtin-types/bool) and call this method from your own job
when you want to own the schedule.
