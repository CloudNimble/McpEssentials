## Summary

Base type for authenticated MCP task stores. Wires the current-user callback, fail-closed
identity, [AuthenticatedMcpTaskStoreBase.InputResponseReceived](/api-reference/CloudNimble/McpEssentials/Core/Tasks/AuthenticatedMcpTaskStoreBase#inputresponsereceived), and the mapping from
`IMcpTaskStore` / [IPerUserMcpTaskStore](/api-reference/CloudNimble/McpEssentials/Core/Tasks/IPerUserMcpTaskStore) into per-user core methods.

## Remarks

Subclass and implement the `Core` methods to persist snapshots. Do not wrap the SDK
`InMemoryMcpTaskStore`; each provider owns its storage.

### <Icon icon="thumbtack" iconType="duotone" color="#419AC5" size={24} className="mr-2" /> GetUserId

Resolves a stable user identifier from *principal*.

#### Syntax

```csharp
public static string GetUserId(System.Security.Claims.ClaimsPrincipal principal)
```

#### Parameters

| Name | Type | Description |
|------|------|-------------|
| `principal` | `System.Security.Claims.ClaimsPrincipal?` | The principal for the current request. |

#### Returns

Type: `string?`
The first non-whitespace claim in SDK session-identity order, or [`null`](https://learn.microsoft.com/dotnet/csharp/language-reference/keywords/null)
when the principal is missing or unauthenticated.

#### Remarks

Claim lookup matches the MCP C# SDK session identity order:
[NameIdentifier](https://learn.microsoft.com/dotnet/api/system.security.claims.claimtypes.nameidentifier), `sub`, [Upn](https://learn.microsoft.com/dotnet/api/system.security.claims.claimtypes.upn),
[Name](https://learn.microsoft.com/dotnet/api/system.security.claims.claimtypes.name), then [Name](https://learn.microsoft.com/dotnet/api/system.security.principal.iidentity.name).
The principal must be authenticated.
